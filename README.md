# Mochi-phone 麻薯手机

AI 角色扮演手机模拟器，集成聊天、角色卡、论坛社区、同人创作、文字游戏（文游）、人设社区、记忆系统和用户中心。整体采用粉色治愈系UI设计。

## 特性

- **AI 聊天**：多角色对话，支持上下文记忆
- **角色卡**：自定义角色创建与社区角色市场
- **社交论坛**：小红书风格社区
  - 关注页：显示当前互动角色自己发布的动态帖子
  - 推荐页：虚拟世界中各种角色的有趣帖子
  - 八卦页：传闻、八卦、小道消息
  - 个人主页：头像编辑、帖子/获赞/关注/粉丝统计、个人帖子列表
  - 帖子混合字数（短50-150字/中150-300字/长300-500字）和多种类型
  - 每条帖子带AI配图描述
- **同人论坛**：完整同人创作模块（LOFTER风格）
  - 标签选择（古代/现代/虐恋/甜文/穿越等+自定义添加/删除）
  - 同人梗管理（破镜重圆/先婚后爱等预设+自定义梗）
  - 文风指令选择（jrsy小手机聊天叙事/LOFTER细腻氛围/随机混合）
  - 随机风格生成（虐心/甜蜜/搞笑/正剧/暗黑），每次内容独一无二
  - 读取用户记忆、人设和人设关系，生成个性化内容
  - 随机标题和作者名，内置LOFTER同人文创作方法论
  - 作品库与书架
  - 「我的」页面作品模块仅显示用户自己发布的作品，AI生成的作品在书架查看
- **文游模块**：32个内置剧本，AI驱动的文字冒险游戏（按moku文游规格书架构）
  - 7个游戏内Tab：剧情/人脉/手机/属性/事件/资产/设置
  - 剧本详情页展示世界观、NPC角色设定、目标任务、存档管理
  - 大分类+小标签二级筛选系统
  - 全中文属性名（资金/员工/品质/库存等，无英文残留）
  - **结构化JSON剧情引擎**：AI返回结构化响应（narrative/stateChanges/options/attributeCheck/isEnding）
  - **属性检定系统**：玩家行动触发属性检定，实时显示成功/失败面板
  - **结局系统**：支持多结局触发，结局达成横幅展示
  - **完整状态管理**：属性变化/背包增减/NPC好感度/事件记录/状态标记，自动持久化
  - **智能建议选项**：AI根据剧情推荐3个行动选项，同时支持自由输入
  - 场景配图描述（每轮剧情自动生成英文配图提示词）
  - 完整存档/读档系统
  - 属性成长、NPC关系、蝴蝶效应
  - 游戏内手机界面（通讯录/社交/地图/日记/商店/任务/背包等）
  - 读取用户人设和人设关系，融入游戏剧情
- **人设社区**：独立顶层模块
  - 官方人设/用户分享/我的人设三个分区
  - 一键导入角色卡
  - 搜索功能
- **记忆系统**：自动将对话总结为记叙文风格记忆
  - 像日记一样叙述对话发生的事件、情感、约定
  - 按类型分类（偏好/事件/禁忌/角色关系/剧情/用户资料）
  - 记录来源对话和消息
- **豆子系统**：完整的虚拟货币经济（服务端扣减，刷新不丢失）
  - AI聊天消耗2颗豆子/条
  - 同人文生成消耗5颗豆子/篇，续写5颗豆子/章
  - 论坛动态生成消耗3颗豆子
  - 评论生成消耗1颗豆子（论坛和同人均扣豆）
  - 文游单轮消耗2颗豆子
  - 生成失败自动退还豆子
  - 所有豆子消耗由服务端即时扣减并持久化，刷新页面豆子不变
  - 只有充值才能增加豆子，新用户赠送30颗体验豆
- **人设系统**：用户人设 + 人设关系
  - 个人人设：描述用户自己的外貌、性格、背景
  - 人设关系：描述用户与各角色之间的关系设定（如青梅竹马、欢喜冤家等）
  - 人设和人设关系会同时注入到聊天、同人文生成、续写、文游的AI prompt中
  - 同人文双主角叙事：角色为第一主角，用户人设为第二主角
- **UI设计**：粉色治愈系风格
  - 主色调：#FF6B9D / #FFB6C1
  - 圆角卡片、柔和阴影
  - 统一视觉语言

## 快速开始

### 本地运行

1. 安装依赖：
```bash
npm install
```

2. 复制环境配置：
```bash
cp .env.example .env
```

3. 编辑 `.env`，填入你的上游API密钥：
```
UPSTREAM_API_KEY=你的真实API密钥
```

4. 启动服务：
```bash
npm start
```

5. 打开浏览器访问 `http://localhost:3000`

### 部署到 Render

1. 将代码推送到GitHub仓库
2. 在Render创建新的Web Service
3. 选择仓库，配置如下：
   - Build Command: `npm install`
   - Start Command: `npm start`
4. 添加环境变量：
   - `UPSTREAM_API_KEY`：你的上游API密钥
   - `DATABASE_URL`：Render PostgreSQL数据库连接串（必填，用于持久化）
   - 其他变量参见 `.env.example`
5. 部署即可

> **重要**：Render免费版文件系统是临时的，服务重启后本地文件丢失。必须配置 `DATABASE_URL` 使用PostgreSQL持久化，否则豆子和用户数据会在重启后丢失。

## 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| UPSTREAM_API_KEY | 上游AI API密钥（必填） | - |
| UPSTREAM_API_BASE | 上游API地址 | https://az.zlapi.vip/v1 |
| UPSTREAM_MODEL | 使用的模型 | [0.005]自营伪流/gemini-2.5-flash |
| CHAT_BEANS_COST | 每次聊天消耗的豆子 | 2 |
| BEANS_PER_CNY | 每元对应的豆子数 | 10 |
| RECHARGE_PACKAGES | 充值套餐（金额:豆子） | 6:60,18:200,30:360,68:900 |
| DEMO_INITIAL_BEANS | 新用户初始豆子 | 30 |
| DATA_DIR | 本地数据存储目录 | .data |
| DATABASE_URL | PostgreSQL连接串（Render部署必填） | - |
| PG_SSL | 是否启用SSL连接数据库 | true |
| PORT | 服务端口 | 3000 |

## 文件结构

前端代码（HTML/CSS/JS）和32个文游剧本均已内嵌在 `server.js` 中，头像图片以独立文件存放在 `public/avatars/` 目录下，通过 express.static 提供静态服务：

```
mochi-phone/
├── server.js          # 主服务文件（包含内嵌前端代码）
├── package.json       # 依赖配置
├── package-lock.json  # 依赖锁定文件
├── README.md          # 本文件
└── public/
    └── avatars/       # 角色头像图片（PNG）
        ├── avatar1.png
        ├── avatar2.png
        ├── avatar3.png
        ├── avatar4.png
        ├── avatar5.png
        ├── avatar6.png
        ├── avatar7.png
        └── avatar8.png
```

## 技术栈

- **后端**：Node.js + Express
- **前端**：原生HTML/CSS/JavaScript（无构建步骤）
- **AI**：兼容OpenAI API格式的上游服务
- **数据持久化**：PostgreSQL（生产） / JSON文件（开发）
