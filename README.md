# AI Phone Simulator

一个AI驱动的手机模拟器平台，集成了AI聊天、AI文游、世界书系统、剧本编辑器等功能，提供沉浸式的AI互动体验。

## ✨ 功能特性

### 📱 手机模拟器界面
- 高仿iOS风格的手机模拟器界面
- 桌面图标、Dock栏、状态栏
- 应用切换动画
- 支持深色/浅色主题切换

### 💬 AI聊天应用
- 流式响应（SSE），打字机效果
- 多会话管理
- 角色卡系统，自定义AI人设
- 世界书设定注入
- 表情支持

### 🎮 AI文游应用
- AI驱动的文字冒险游戏
- 自由输入 + 选项式交互
- 属性系统（生命值、法力、体力、金币）
- 存档/读档功能
- 世界观和角色设定注入

### 📚 世界书系统
- 世界观设定管理
- 角色卡管理
- 地点卡管理
- 设定条目开关
- JSON导入/导出

### ✏️ 剧本编辑器
- 节点式可视化编辑器
- 拖拽节点、连线
- 分支剧情编辑
- 实时预览功能
- 本地自动保存

### ⚙️ 设置/配置中心
- API地址和密钥配置
- 模型选择和温度调节
- 界面主题和字体大小设置
- 数据导入/导出/清除
- API连接测试

## 🚀 快速开始

### 方式一：Node.js 后端部署（推荐）

1. **安装依赖**
```bash
npm install
```

2. **配置环境变量**
```bash
cp .env.example .env
```

编辑 `.env` 文件，填入你的API配置：
```env
API_BASE_URL=https://az.zlapi.vip/v1
API_KEY=sk-your-api-key-here
PORT=3000
```

3. **启动服务**
```bash
npm start
```

4. **访问应用**
打开浏览器访问 `http://localhost:3000`

### 方式二：纯前端部署

1. 将所有文件部署到任意静态文件服务器
2. 在设置页面手动配置API地址和密钥

> 注意：纯前端模式下API密钥会暴露在前端，仅建议在本地或可信环境使用

## 🔧 API 配置

### 支持的API格式
- OpenAI 兼容格式（Chat Completions）
- 支持流式响应（SSE）

### 环境变量说明

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `API_BASE_URL` | API 基础地址 | `https://az.zlapi.vip/v1` |
| `API_KEY` | API 密钥 | 空 |
| `PORT` | 服务端口 | `3000` |
| `DEFAULT_MODEL` | 默认模型 | `gpt-3.5-turbo` |
| `MAX_TOKENS` | 最大 token 数 | `2048` |
| `TEMPERATURE` | 温度参数 | `0.7` |

## 🎯 使用指南

### 1. 配置API
- 打开「设置」应用
- 填入API地址和密钥
- 点击「测试连接」验证
- 选择默认模型和温度

### 2. 创建世界书
- 打开「世界书」应用
- 创建世界观、角色卡、地点卡
- 添加详细的设定条目
- 设定条目可以单独开关

### 3. 开始AI聊天
- 打开「AI聊天」应用
- 点击工具栏的角色/世界按钮选择设定
- 开始对话，AI会按照设定回复

### 4. 体验AI文游
- 打开「AI文游」应用
- 选择角色和世界
- 点击「开始新游戏」
- 通过选项或自由输入推进剧情

### 5. 编辑剧本
- 打开「剧本编辑」应用
- 添加节点，拖拽排列
- 连接节点创建分支
- 点击「预览」测试剧本

## 💾 数据存储

所有数据默认存储在浏览器的 localStorage 中：
- 聊天记录
- 游戏存档
- 世界书设定
- 剧本数据
- 设置配置

可以在设置页面导出完整备份，或导入之前的备份数据。

## 🔒 安全提示

- 后端代理模式下，API密钥保存在服务端，更安全
- 纯前端模式下，API密钥会存储在浏览器本地，请注意保护
- 请勿在公共设备上保存敏感的API密钥
- 建议定期导出数据备份

## 🎨 技术栈

**后端：**
- Node.js + Express
- SSE 流式响应
- dotenv 环境变量

**前端：**
- 原生 JavaScript（无框架依赖）
- CSS3 动画和过渡
- LocalStorage 数据持久化
- SVG 连线绘制
