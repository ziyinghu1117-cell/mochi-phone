# 🍡 Mochi-Phone

> 温柔陪伴 · 文游世界 — 一个开源的 AI 陪伴 + 文字游戏平台

Mochi-Phone 是一个纯前端的 AI 角色聊天 + 文字冒险游戏平台，灵感来自 moku文游、UU模拟器、jrsy小手机等应用，但在功能丰富度和可定制性上更进一步。

## ✨ 核心功能

### 💬 AI 角色聊天
- 自定义角色：人设、性格、开场白、场景、对话示例
- 流式输出，实时显示 AI 回复
- 支持关联世界书，让角色更了解你的世界

### 📖 文字冒险游戏（文游引擎）
- 内置 4 个剧本：浮生六记、深宫谋略、无限回廊、碧波问道
- 属性系统：体力、修为、铜钱等，随剧情变化
- 多选项决策 + 自由输入行动
- 存档 / 读档系统，随时保存进度
- 世界书自动注入，让游戏世界更丰满

### 🌐 世界书系统
- 关键词触发：对话中出现关键词时自动注入对应条目
- 常驻条目：始终注入上下文
- 优先级排序：重要条目优先注入
- 全局设定：定义整个世界的基础规则

### ✨ 记忆沉淀
- 聊天后 AI 自动提取关键信息（偏好、事件、关系）
- 记忆持久化存储，后续对话自动注入
- 手动增删改查记忆

### ✏️ 同人文生成器
- 选择角色 CP（支持角色×角色、角色×自己）
- 标签系统：古代、现代、甜文、虐恋、穿越等
- 同人梗：破镜重圆、先婚后爱、青梅竹马等
- 字数选择：短篇 / 中篇 / 长篇
- 风格选择：虐心 / 甜蜜 / 搞笑 / 正剧

### 💌 AI 论坛
- 让 AI 角色自动生成社交媒体动态
- 点赞互动

### 🎨 更多特性
- 📱 仿手机 UI，桌面端居中显示，移动端全屏
- 🎨 4 套主题：粉色 / 蓝色 / 绿色 / 暗色
- 📏 3 级字号调节
- 🍡 豆子货币系统（每日签到领取）
- 💾 纯本地存储（localStorage），数据不上传服务器
- 📤 数据导出 / 导入备份
- 🔌 兼容所有 OpenAI 格式的 API

## 🚀 快速开始

### 方式一：直接打开
1. 下载项目文件
2. 用浏览器打开 `index.html` 即可使用

### 方式二：部署到 GitHub Pages
1. 将项目文件上传到 GitHub 仓库
2. 进入仓库 Settings → Pages
3. Source 选择 `main` 分支，目录选 `/ (root)`
4. 保存后等待几分钟，即可通过 `https://你的用户名.github.io/仓库名/` 访问

### 方式三：本地服务器（推荐）
```bash
# 使用 Python
python3 -m http.server 8080

# 或使用 Node.js
npx serve
```
然后浏览器访问 `http://localhost:8080`

## ⚙️ 配置 API

首次使用需要配置 API：

1. 打开应用，进入「我的」→「设置」
2. 填写 API 地址（默认已配置）
3. 填写 API 密钥（默认已配置）
4. 选择模型（推荐 `gpt-4o-mini`，性价比最高）
5. 点击「测试连接」确认可用

### 支持的 API 格式
任何兼容 OpenAI `/v1/chat/completions` 格式的 API 均可使用：
- OpenAI 官方 API
- 各类中转站 / 代理
- 本地部署的 LLM（如 text-generation-webui、ollama 等）

## 🔒 安全提示

> **重要：** `js/config.js` 中包含 API 密钥。如果你要将项目放到公开的 GitHub 仓库，强烈建议：
> 1. 将 `apiKey` 改为空字符串 `''`
> 2. 在应用内「设置」页面手动填写密钥
> 3. 密钥存储在浏览器本地，不会随代码泄露

## 🎮 使用指南

### 创建角色
1. 进入「角色」页，点击「＋ 创建」
2. 填写头像、名字、标签、人设、开场白等
3. 可选关联一本世界书
4. 保存后即可在「聊天」页与角色对话

### 玩文游
1. 进入「文游」页，选择剧本库中的剧本
2. 点击「进入剧本」开始游戏
3. 阅读剧情后选择选项，或自由输入行动
4. 随时点击「💾 存档」保存进度
5. 在「我的存档」中可读取之前的存档

### 世界书
1. 进入「世界书」页，点击「＋ 新建」
2. 填写世界名称和全局设定
3. 添加条目：标题、关键词、内容、优先级、是否常驻
4. 在角色设置中关联世界书，或文游剧本中引用

## 🛠️ 技术栈

- 纯原生 HTML / CSS / JavaScript（无框架、无依赖）
- localStorage 数据持久化
- Fetch API + SSE 流式传输
- CSS 变量实现主题切换
- 响应式设计（桌面 / 移动端自适应）
