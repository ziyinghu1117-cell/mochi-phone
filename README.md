# Mochi AI Chat - AI 角色聊天平台

一款治愈系 AI 角色聊天平台，支持自定义角色、社区分享、论坛社区、同人文创作、个性装扮、米粒计费和管理员充值系统。

## ✨ 功能特性

- 🎭 **自定义角色** - 创建你专属的 AI 角色，设定人设、性格、说话方式
- 💬 **流式聊天** - 支持 SSE 流式输出，打字机效果，实时响应
- 🌐 **角色社区** - 分享你的角色，发现更多有趣的角色
- 💬 **论坛社区** - AI 生成的趣味帖子，关注、推荐、八卦三大板块
- 📖 **同人文创作** - AI 一键生成同人文，多种梗和分类可选
- 🎨 **个性装扮** - 自定义 UI 样式、聊天气泡、聊天壁纸
- 💰 **米粒系统** - 按量计费，新用户注册赠送 1000 米粒
- 🔐 **管理员后台** - 完整的充值管理、用户管理、数据统计
- 📱 **移动端适配** - 完美适配手机端，随时随地聊天

## 🚀 快速开始

### 环境要求

- Node.js 18+
- npm 或 yarn

### 本地运行

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入你的 API 配置

# 3. 启动服务
npm start

# 4. 访问
# 打开浏览器访问 http://localhost:3000
```

### Render 部署

1. 将项目推送到 GitHub 仓库
2. 在 Render 中创建新的 Web Service
3. 连接你的 GitHub 仓库
4. 配置环境变量（在 Render 后台的 Environment 中设置）
5. 部署完成后即可访问

> **注意**：Render 文件系统是临时的，重启会丢失数据。建议挂载 Render Disks 持久化存储，将 `DATA_DIR` 设置为挂载目录。

## ⚙️ 环境变量配置

复制 `.env.example` 为 `.env` 并填入实际值：

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `API_BASE_URL` | OpenAI 兼容 API 地址，支持带或不带 `/v1` 结尾 | - |
| `API_KEY` | API 密钥 | - |
| `MODEL` | 使用的模型名称 | `gpt-3.5-turbo` |

**API 地址智能拼接：**
- 填 `https://api.openai.com/v1` → 请求 `https://api.openai.com/v1/chat/completions`
- 填 `https://api.openai.com` → 自动加 `/v1/chat/completions`

## 💬 论坛系统

### 功能说明

论坛系统提供 AI 生成的趣味帖子内容，分为三大板块：

- **关注** - 你关注的角色发布的第一人称帖子
- **推荐** - 各种类型的混合推荐内容
- **八卦** - 话题性强的八卦讨论帖

### 核心功能

- 📝 **AI 生成帖子** - 消耗米粒自动生成有趣的帖子内容
- ❤️ **点赞收藏** - 喜欢的帖子可以点赞和收藏
- 💬 **评论互动** - 查看评论，发表自己的评论
- 🔔 **关注角色** - 关注喜欢的角色，他们的帖子会出现在关注页
- 🔥 **热搜榜** - 查看当前热门话题

### 入口位置

「我的」页面 → 更多应用 → 论坛

## 🔐 管理员后台

### 访问方式

访问地址：`https://你的域名/admin`

默认密码：`841026`（可通过 `ADMIN_PASSWORD` 环境变量修改）

### 功能说明

#### 📊 数据概览
- 总用户数、总充值米粒、总消耗米粒
- 待处理充值订单数
- 角色总数、对话总数、订单统计

#### 💰 充值管理
- **待处理** - 查看等待确认的充值申请
- **已完成** - 已确认到账的订单
- **已拒绝** - 已拒绝的订单
- **全部** - 所有订单列表

操作：
- **确认到账** - 点击后给用户增加对应米粒，订单标记为已完成
- **拒绝** - 拒绝充值申请，可填写拒绝原因

#### 👥 用户管理
- 查看所有用户列表
- 搜索用户（按用户名或昵称）
- 手动调整用户米粒（增加/扣除）
- 查看用户注册时间和当前余额

### 实时通知

管理员后台每 5 秒自动轮询一次，有新的充值申请时：
- 侧边栏显示红色数字徽章
- 浏览器标签页标题显示待处理数量
- 充值管理页面自动刷新列表

## 💳 充值流程

### 用户端流程

1. 进入「我的」页面，点击「充值」
2. 选择充值档位（11个档位可选）
3. 显示微信收款码和用户 ID
4. 用户扫码付款，**备注用户 ID**
5. 点击「我已付款，提交申请」
6. 等待管理员确认，通常 5 分钟内到账
7. 可在「充值记录」中查看申请状态

### 管理员端流程

1. 登录管理员后台
2. 收到新充值申请通知（红点提示）
3. 查看收款账户确认是否到账
4. 核对用户 ID 和金额
5. 点击「确认到账」→ 用户米粒自动增加
6. 或点击「拒绝」→ 填写拒绝原因

## 🐛 常见问题

### 聊天没有回复？

1. 检查 `API_BASE_URL` 和 `API_KEY` 是否正确
2. 确认 API 地址格式（支持带或不带 `/v1`）
3. 查看浏览器控制台和服务器日志获取详细错误信息

### 流式输出不生效？

Render 等平台可能会缓冲 SSE 响应，系统已添加以下优化：
- 设置 `X-Accel-Buffering: no` 响应头
- 如果流式失败自动降级为普通请求

### 米粒不足怎么办？

1. 用户可以通过充值获得米粒
2. 管理员可以在后台手动调整用户米粒
3. 论坛发帖、同人文生成都会消耗米粒

### 数据会丢失吗？

- 本地运行：数据保存在 `data/` 目录，不会丢失
- Render 部署：默认文件系统是临时的，重启会丢失。建议挂载 Render Disks 持久化存储
