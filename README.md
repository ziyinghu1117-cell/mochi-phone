# Mochi AI Chat - 商用AI角色聊天平台

一款治愈系AI角色聊天平台，对标星野AI移动端交互体验，支持自定义角色、社区分享、个性装扮等功能。

## ✨ 功能特性

### 🎭 角色聊天
- 左右气泡布局，支持头像展示
- SSE流式输出，打字机逐字渲染
- 顶部角色切换栏，左右滑动切换
- 对话历史本地永久存储
- 支持清空当前对话

### 👥 角色管理
- 创建自定义角色（头像、名称、人设、简介、标签）
- 编辑角色信息，不影响历史对话
- 删除角色（二次确认）
- 角色公开/私密设置

### 🌐 角色社区
- 社区广场展示公开角色
- 角色详情页查看完整人设
- 一键导入社区角色到本地
- 搜索筛选（最热/最新）

### 💰 豆子计费系统
- 虚拟货币「豆子」体系
- 对话前预扣豆子，失败自动返还
- 多档位充值套餐
- 消费明细记录

### 🎨 自定义装扮
- **页面UI自定义**：全局CSS样式覆盖
- **聊天气泡自定义**：仅作用于气泡样式
- **聊天壁纸自定义**：上传图片+透明度+模糊度
- 安全过滤危险内容

### 👤 个人中心
- 个人资料编辑（昵称、头像、简介）
- 豆子余额查看
- 充值中心
- 豆子明细
- 清空缓存

## 🚀 快速开始

### 环境要求
- Node.js >= 16.0.0
- npm 或 yarn

### 安装部署

```bash
# 1. 解压项目
unzip mochi-ai-chat.zip
cd mochi-ai-chat

# 2. 安装依赖
npm install

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入你的API密钥等配置

# 4. 启动服务
npm start

# 5. 访问应用
# 浏览器打开 http://localhost:3000
```

## ⚙️ 配置说明

所有配置都在 `.env` 文件中，复制 `.env.example` 后修改即可。

### 上游API配置
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `API_BASE_URL` | 上游API地址（OpenAI兼容格式） | `https://us.noviapi.com/v1` |
| `API_KEY` | 上游API密钥 | `your_api_key_here` |
| `DEFAULT_MODEL` | 默认使用的模型 | `gpt-3.5-turbo` |
| `API_COST_PER_CALL` | 上游单次调用成本（元，用于成本核算） | `0.01` |

### 服务器配置
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `PORT` | 服务监听端口 | `3000` |
| `NODE_ENV` | 运行环境 | `development` |

### 豆子计费配置
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `COST_PER_MESSAGE` | 单次AI对话消耗豆子数 | `10` |
| `BEANS_PER_YUAN` | 1元人民币兑换豆子数 | `100` |
| `NEW_USER_BEANS` | 新用户初始赠送豆子数 | `100` |

### 充值档位配置
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `RECHARGE_TIERS` | 充值档位列表（格式：价格:豆子数,价格:豆子数） | `6:600,30:3000,68:6800,128:12800,328:32800,648:64800` |

### 社区配置
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `COMMUNITY_PAGE_SIZE` | 社区单页加载数量 | `20` |

## 🔒 安全说明

1. **API密钥安全**：上游API密钥仅存储在后端 `.env` 文件中，前端代码不会暴露任何密钥
2. **请求中转**：所有AI对话请求必须经由后端中转，前端不直接调用上游API
3. **装扮安全**：自定义装扮仅支持纯CSS样式覆盖，自动过滤script标签、JS代码等危险内容
4. **数据隐私**：用户本地数据（角色、对话历史、装扮设置）仅保存在浏览器端
5. **参数校验**：后端接口做好参数校验，防止恶意请求

## 🎨 UI设计风格

- **主色调**：粉色系（#FF9EC8、#FFB8D6），柔和少女风
- **背景**：浅粉色渐变，温馨治愈
- **卡片**：白色圆角卡片，轻微阴影
- **按钮**：粉色渐变胶囊按钮
- **布局**：移动端优先，竖屏设计
- **底部导航**：4个Tab（聊天、角色、社区、我的）

## 🔧 技术栈

- **前端**：纯HTML + CSS + 原生JavaScript
- **后端**：Node.js + Express
- **API**：OpenAI兼容格式 /v1/chat/completions
- **存储**：localStorage（前端）、内存Map（后端）
- **流式响应**：SSE (Server-Sent Events)

## 📱 适配说明

- 触控友好，按钮尺寸适合手指点击

## 🚀 部署到生产环境

### 使用 Render 部署
1. 将代码推送到 GitHub 仓库
2. 在 Render 上创建新的 Web Service
3. 连接 GitHub 仓库
4. 配置环境变量（在 Render 控制面板中设置）
5. 部署命令：`npm install && npm start`

### 使用 Vercel 部署
需要配置 serverless 函数，或使用 Express 适配器。

### 使用 Docker 部署
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install --production
COPY . .
EXPOSE 3000
CMD ["npm", "start"]
```

## 📝 注意事项

1. 当前版本用户数据存储在内存中，服务重启后会丢失，生产环境建议接入数据库
2. 充值功能为模拟实现，生产环境需要对接真实支付平台
3. 社区角色数据存储在内存中，生产环境建议持久化存储
4. 建议配置 HTTPS，确保数据传输安全
